# Coding task

Do the coding task yourself, directly in the repository's working tree:

1. Read only what you need to understand the change.
2. Make the change with your editing tools.
3. Verify it with the project's own checks, and fix what fails.
4. Report briefly what you changed and the check results.

Don't commit unless the user asks.
